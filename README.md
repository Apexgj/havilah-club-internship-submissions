# Havilah Club Internship — Submission Repository

This repository contains weekly task submissions for the Havilah Club 8-week AI & Robotics Internship Programme.

## Structure

```
week-3/
    day-11-introduction-to-python/
    day-12-python-logic-functions/
    day-13-working-with-data/
    day-14-python-apis/
    day-15-automation-project/
```

## Submission Guidelines

1. Complete each task in its designated folder.
2. Do not modify files outside your assigned folder.
3. After completing a task, share your progress on LinkedIn, X (Twitter), or Instagram.
4. Submit both your GitHub repo link and your social media post link on the platform.

## Requirements

- Python 3.x
- Install dependencies per task: `pip install -r requirements.txt` (where applicable)
- Never commit `.env` files — use `.env.example` as reference only.
