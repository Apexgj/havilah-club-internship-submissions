## Automated Checks

Every time you push to this repository, GitHub runs automated submission checks on your work. You do not need to set anything up — they run automatically.

### How to see your results

1. Go to your repository on GitHub.
2. Click the **Actions** tab at the top.
3. Click the most recent workflow run to open it.
4. Each day appears as a separate job in the left panel.

### What the checks look for

The checks do not grade your work — your instructor does that. They only verify that everything required has been submitted correctly.

| Day | What is checked |
|-----|-----------------|
| 11 | `main.py` is present, not empty, and has no syntax errors |
| 12 | `main.py` is present, not empty, `calculate_grade` is defined |
| 13 | `main.py`, `data/sample.csv`, and `data/output.csv` are all present and non-empty |
| 14 | `main.py` is present, `import requests` is used, `.env.example` is committed, `.env` is not |
| 15 | `main.py` is present, `README.md` is filled in (no placeholder text), `data/` folder exists |

### Reading the results

- **Green checkmark** — all checks passed for that day. Your submission is complete.
- **Red X** — something is missing or has an error. Click the failed job, then click the failing step to read the exact error message and fix it.

The workflow only runs checks for days where files have changed, so pushing a fix for Day 13 will not re-run the Day 11 checks unnecessarily.
